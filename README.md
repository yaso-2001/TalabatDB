
# TalabatDB

## Project Description
TalabatDB is a food delivery database project developed using Microsoft SQL Server.

The database stores information about customers, restaurants, menu items, orders, and payments.

## Database Tables
The database contains 6 tables:

1. Customers - Stores customer information.
2. Restaurants - Stores restaurant information.
3. MenuItems - Stores food and drink items.
4. Orders - Stores customer orders.
5. OrderItems - Stores the items included in each order.
6. Payments - Stores payment information.

## Database Features
- Primary keys and foreign keys
- Identity columns
- Check constraints
- Default values
- Relationships between tables
- Sample Egyptian restaurant data

## Technologies Used
- Microsoft SQL Server
- SQL
- SQL Server Management Studio (SSMS)

## How to Run
1. Download or clone this repository.
2. Open `TalabatDB.sql` in SQL Server Management Studio.
3. Execute the SQL script.
4. The database and sample data will be created.
